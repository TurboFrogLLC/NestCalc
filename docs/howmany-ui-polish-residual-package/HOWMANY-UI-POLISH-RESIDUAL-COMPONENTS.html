Behavior contract

• Quick chips: transient blink on press only — never sticky.
• Chip sets the focused field value (replace, not append).
• Chips row scrolls horizontally when there are more values.
• ← → always visible; move focus between numeric fields without changing values.
• Lucide Calculator expands shell right only; number keys stay fixed; orange + − × ÷ slide in.
• Overall pad height is constant — mid slot swaps arrows/chips ↔ tall LCD.
• Enter always full-width under the pad.
• Toolbar: Lucide Calculator · Backspace · Pencil · drag · Close (no arrows in toolbar).
• Keypad mode: ← → strip + quick chips under toolbar.
• When relevant collapsibles are closed, keypad is inert for those fields.
• Site-wide: numeric-only inputs reject letters.
